1D Boundary-Value Finite Element Solver

A Galerkin finite element workflow for a one-dimensional boundary-value problem.

Problem and method

The program reads a text input defining the mesh, coefficients, loads, and boundary conditions. It validates the input, forms element stiffness and force terms using shape functions and Galerkin's method, and assembles the global linear system.

Boundary conditions and outputs

The implementation handles prescribed values and natural or mixed boundary terms, solves for nodal primary unknowns, and computes secondary quantities and residual norms. It writes results to a text file and plots primary and secondary unknowns against position.

Evidence and limits

The report documents the algorithm and output workflow but does not provide a numerical benchmark table. This page therefore describes implemented functionality without claiming a measured accuracy or speedup.
